CarMind v22 — TREATMENT DIAGNOSTICS

This build sends SAFE Android diagnostic status to the Treatment Console.

Reports:
- app start
- wake detected
- microphone/speech-recognizer errors
- training match
- command received/not understood
- media play request/result text
- navigation request
- Bluetooth connect request
- payment/access state

Does NOT send:
- customer conversations
- voice audio
- passwords
- card details
- API secrets

Use with the matching CarMind v8 Treatment Android Diagnostics server package.
