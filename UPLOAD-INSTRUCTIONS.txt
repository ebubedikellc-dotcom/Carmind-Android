CARMIND AI v1.8.2 — PRIVATE MUSIC AND VIDEO LIBRARIES

This package contains the two real Android applications:
- Carmind Car
- Carmind Mobile

Whisper.cpp remains completely removed. Both apps use the free offline Vosk
listener. This update keeps partial Bluetooth phrases until the driver stops,
restarts interrupted listening, remembers spoken pronunciation corrections and
preserves them when Settings is saved. The existing Carmind design, commands,
media, contacts, calling and text-to-speech recovery changes remain.
Music is read only from Music or Songs folders. Videos are read only from
Movies, Music Videos or Videos folders. WhatsApp, Telegram, voice notes,
recordings, sent items, statuses, chat folders and unknown folders are blocked.

GITHUB / CODEMAGIC
1. Extract this delivery ZIP.
2. Upload these three files to the TOP LEVEL of the GitHub repository:
   - Carmind-project.zip
   - codemagic.yaml
   - UPLOAD-INSTRUCTIONS.txt
3. Do not upload the outer delivery ZIP into the repository.
4. In CodeMagic, refresh the application and select:
   Carmind AI - Installable Debug APK
5. Start a new build.
6. Download both artifacts:
   - app-debug.apk (Carmind Car)
   - phone-debug.apk (Carmind Mobile)
7. Uninstall the previous APK before installing v1.8.2 so Android
   cannot retain the earlier app package data.
8. Open Carmind and grant microphone permission. The first launch downloads
   nothing: CodeMagic already bundles the verified Vosk model into the APK.

The repository configuration file must remain named exactly codemagic.yaml.
