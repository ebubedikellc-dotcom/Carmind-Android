This upload contains the official whisper.cpp native source. CodeMagic
automatically downloads and verifies the free ggml-base.en-q5_1 model before
building both APKs. The finished APKs contain the model and do not require a
paid speech API for voice recognition.

Version 1.7.3 repairs the installed APK's silent-listener fault: it accepts
quieter phone/Bluetooth speech, blocks overlapping microphone sessions, and
automatically releases the listening pause if Android TTS omits its finish event.

Before public release, install both APKs and perform the final acceptance test
on the exact Android phone/car combination. Confirm microphone permission,
“Hello Mercedes” during media playback, Bluetooth microphone routing, engine
noise rejection, Nigerian-English commands, calls, contacts, local media,
YouTube and Spotify handoff. Android and individual cars may route Bluetooth
microphones differently, so this physical test cannot be replaced by a source
code test.
