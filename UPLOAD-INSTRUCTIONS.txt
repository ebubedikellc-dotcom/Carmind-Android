CARMIND AI PRODUCTION SOURCE — TWO-APP PACKAGE v1.6.5

This one package produces TWO Android apps:

1. app-debug.apk — Carmind Car (install on the Android car screen)
2. phone-debug.apk — Carmind Mobile (install on the Android phone)

This is the real GitHub/Android source package, not a picture or mock-up. The
browser page is only an interface preview. The Android modules and CodeMagic
workflow produce the installable apps. The release workflow produces the AAB
that must be signed with the owner's private release key for store distribution.
