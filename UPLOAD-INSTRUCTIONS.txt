CARMIND AI v1.9.4 — VERIFIED PRONUNCIATION LEARNING

This package contains the two real Android applications:
- Carmind Car
- Carmind Mobile

Whisper.cpp remains completely removed. Both apps use the free offline Vosk
listener. This version keeps the old-attempt correction and teaches three
genuinely different phrases for every action. For Media, Carmind asks the customer
to say “Open Media,” “Go to Media,” and “Show my music and videos.” All three
pronunciations are stored as the same Media action. Personal training shows attempts
1, 2 and 3, says “Talk now” before opening the microphone, visibly marks every
successful phrase as passed, and then moves to the next action. The complete
138-recording profile is retained, including the first Media lessons. The training
screen now displays the current action name and exact current phrase, without the
old translation layer freezing the visible words on “Open Media.” Carmind does
not dictate what the customer must say. It asks how the customer personally says
each action, then automatically asks them to repeat their own wording three times.
Only three consistent hearings are saved as that customer's pronunciation. It actively
selects the car Bluetooth microphone and rejects
low-confidence one-word engine-noise bursts, detects a silent microphone stream
and rebuilds it automatically. It also keeps partial Bluetooth phrases until the driver stops,
restarts interrupted listening, remembers spoken pronunciation corrections and
preserves them when Settings is saved. The existing Carmind design, commands,
media, contacts, calling and text-to-speech recovery changes remain.
Saying only "Play" starts the exact item already displayed in Now Playing.
Named requests search the customer's approved media by title, artist, album,
folder and genre, including commands such as "Play drills", "Play Davido",
"Look for ODC Beats", "Open Media" and "Open Spotify".
Settings now includes Nigerian Intonation Mode and a voice-openable Nigerian
Voice School. Media actions come first; every important action presents three
different natural phrases. Those private phrase mappings remain
on that device and are applied to future commands. Carmind reacts 0.8 seconds after
speech activity stops. Only an incomplete Bluetooth wake opening such as
"Hello" receives up to 2.2 seconds for the remaining words.
Music is read only from Music or Songs folders. Videos are read only from
Movies, Music Videos or Videos folders. WhatsApp, Telegram, voice notes,
recordings, sent items, statuses, chat folders and unknown folders are blocked.

GITHUB / CODEMAGIC
1. Extract this delivery ZIP.
2. Upload these three files to the TOP LEVEL of the GitHub repository:
   - Carmind-project.zip
   - codemagic.yaml
   - UPLOAD-INSTRUCTIONS.txt
3. Do not upload the outer delivery ZIP into the repository.
4. In CodeMagic, refresh the application and select:
   Carmind AI - Installable Debug APK
5. Start a new build.
6. Download both artifacts:
   - app-debug.apk (Carmind Car)
   - phone-debug.apk (Carmind Mobile)
7. Uninstall the previous APK before installing v1.9.4 so Android
   cannot retain the earlier app package data.
8. Open Carmind and grant microphone permission. The first launch downloads
   nothing: CodeMagic already bundles the verified Vosk model into the APK.

The repository configuration file must remain named exactly codemagic.yaml.
